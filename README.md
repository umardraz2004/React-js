# React.js Learning Projects

This repository contains all the projects I've built while learning React.js concepts.

## 📚 Projects Overview

Each folder represents a different React concept or project:

- **Calculator in React** - Basic calculator application
- **Components & Props** - Understanding React components and props
- **Dynamic data & State** - Working with state and dynamic data
- **Form in React** - Form handling and validation
- **Investment calculator in React** - Investment calculator app
- **Tic Tac Toe in React** - Classic game implementation
- **Refs and portal in react** - Using refs and portals
- **composition, context_Api, useReducer** - Advanced state management patterns
- **Custom hooks in react** - Creating and using custom hooks
- **Place Picker (useEffect)** - Understanding useEffect hook
- **React Routers** - Client-side routing
- **advance react routing** - Advanced routing concepts
- **Advaced-redux** - Redux state management
- **redux-counter** - Simple Redux counter app
- **Learning http request in react** - Making HTTP requests
- **PMS** - Project Management System
- **ts-project** - TypeScript with React

## 🎯 Purpose

This repository serves as my learning journey through React.js, covering everything from basics to advanced concepts.

## 🚀 Getting Started

Each project folder contains its own `package.json` and can be run independently:

```bash
cd [project-folder]
npm install
npm start
```
